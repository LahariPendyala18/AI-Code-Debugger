# AI Code Debugging & Explanation

## Project Description

AI Code Debugging & Explanation is an AI-based application
that helps users identify and understand programming errors.

The application is developed using Python and Streamlit.

Users can enter code and select the programming language.
The AI analyzes the code and provides error explanations,
corrected code, and suggestions.

## Technologies Used

- Python
- Streamlit
- Gemini API
- Pandas
- NumPy
- Scikit-learn
- LangChain
- NLTK
- spaCy
- Transformers
- PyTorch
- GitPython
